# Скорость открытия SideWidget

14 ноября 2026 года. Windows, сборка Release x64 с комплектным WebView2 156.0.4314.58. Отдельные профили с настройками по умолчанию. В профиле для двух окон выбраны оба подключённых монитора.

| Медиана, мс | Одно окно | Два окна |
| --- | ---: | ---: |
| От запуска процесса до показа шапки | 547,3 | 502,6 |
| От запуска процесса до готовности главной в основном окне | 1123,2 | 1112,9 |
| От получения `WM_HOTKEY` до применения геометрии раскрытия | 11,0 | 16,5 |
| От получения `WM_HOTKEY` до подтверждения фокуса поиска | 21,9 | 33,6 |

Для каждой конфигурации выполнено три запуска процесса и по пять раскрытий после готовности главной. При двух окнах указатель находился на втором мониторе. Поиск получил фокус во всех 30 открытиях, окно SideWidget было на переднем плане. Диапазон времени до фокуса — 13,6–31,6 мс с одним окном и 13,8–49,2 мс с двумя.

Профиль WebView2 использовался повторно внутри каждой серии, кэш Windows не сбрасывался. Время раскрытия измерено до применения геометрии окна. Фокус подтверждает WebView2 после обновления React. Время выдачи результатов Everything и момент физического вывода кадра не измерялись.

Сырые выборки: `output/opening-samples/one.json` и `output/opening-samples/two.json`. Повторить замер можно через `scripts/measure-opening.py`.
