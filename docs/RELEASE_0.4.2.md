# SideWidget 0.4.2

- В свёрнутой панели часы остаются по центру, справа отображается прежний кружок лимитов Codex. Внешнее кольцо показывает неделю, внутреннее — 5 часов. Автопоказ при запущенном Codex; отдельное отключение в настройках часов. Неизвестный остаток отображается пунктиром.
- Кружок Codex рядом с закреплёнными приложениями можно отключать отдельно. Ярлыки добавляются перетаскиванием из Проводника; порядок приложений меняется перетаскиванием.
- Уборка рабочего стола использует явный выбор действия и правил. Сохраняются предпросмотр, частичные результаты и отмена.
- Исправлено получение значков для локальных ярлыков; объединены накопленные исправления установки, таймеров и переводов.

Сохранены монитор чатов Codex, календарь, монитор сайтов и телефонный пульт. Данные и настройки находятся в прежнем пользовательском каталоге.

Проверки объединённой версии: 286 веб-тестов, 1113 основных C#-проверок, проверки телефонного пульта, 10 проверок Windows API, 30 проверок нескольких мониторов, каталоги переводов и сборки Windows/веб-интерфейса. Публичные сетевые пробы Windows отключены.

Для обычной установки рекомендуется Lite; полный Portable включает зависимости. Оба варианта и зависимости Lite публикуются с SHA-256.
