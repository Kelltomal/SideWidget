# SideWidget 0.4.4

В центре кружка Codex вместо ромба теперь отображается целый процент остатка за неделю, без знака процента. Число не подменяется остатком за 5 часов. Кольца и подробная подсказка сохраняют оба периода.

Однозначные и двухзначные значения выровнены по центру. Для `100` используется немного меньший шрифт; остаток меньше 1% обозначается `<1`, неизвестный — `—`.

Проверены реальные изображения `7`, `42` и `100` в WinUI-шапке, прозрачной полоске высотой 23 DIP и веб-ярлыке. Часы остаются по центру панели; включение и отключение индикатора не сдвигает их.

Проверки: 293 веб-теста, 1119 основных C#-проверок, TypeScript/production build и нативная сборка. Скриншоты в `docs/screenshots/codex-weekly-*.png` используют демонстрационные значения.
