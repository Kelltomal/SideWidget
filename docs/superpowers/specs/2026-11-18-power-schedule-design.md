# Разовый таймер питания

Утверждено пользователем: в меню «Питание» добавить «Выключить через…» и
«Перезагрузить через…». Поля «Часы» и «Минуты» складываются; пустое поле
считается нулём. При 0 и 0 показать предупреждение и ничего не назначать.
Один активный запуск, обратный отсчёт и отмена в разделе «Таймер».

Подход: общий для окон таймер внутри SideWidget. При истечении удалить
задание до вызова существующего QuickActions.Power, чтобы выполнить ровно
один раз без принудительного закрытия приложений. SideWidget должен быть
запущен; выход отменяет задание. Альтернатива shutdown.exe /t с задержкой
не подходит: Windows может принудительно завершать приложения.
Предельная задержка — 24 часа; минуты 0–59. Существующие таймеры независимы.
Новый запуск заменяет старый только после подтверждения. Ошибки видимы.
Сохранить Medeo, текущие формы и темы. Проверки используют подставное
действие; реальное выключение во время проверки не запускать.
