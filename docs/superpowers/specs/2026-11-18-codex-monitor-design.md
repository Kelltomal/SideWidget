# Codex: чаты, лимиты и разовое выключение

Пользователь утвердил инструмент Codex в SideWidget: список локальных
чатов, реальные статусы, лимиты и время их сброса; выключение после
выбранных или всех текущих активных чатов с 60 секундами на отмену.
Дополнение пользователя: отдельный переключатель выключения при нулевом
лимите, один раз за текущую сессию ПК, не циклично.

Читать только метаданные локальных SQLite Codex в read-only режиме,
не менять чаты и не читать/передавать их сообщения, ключи или auth.json.
Состояния completed, inProgress, failed, interrupted проверены на хосте.
Успех — completed с временем завершения и без очереди. Ожидание ответа,
ошибка, прерывание, исчезновение данных не являются успехом. Все текущие
активные означает зафиксированный при включении набор; новые чаты не
подмешиваются молча. При новой работе выбранного чата отсчёт отменяется.

Официальный источник лимитов: account/rateLimits/read установленного
Codex app-server. При сбое API данные недоступны; rollout не читается. Не считать
контекстные токены квотой тарифа. Показывать источник/время получения и
недоступность; устаревший, отсутствующий лимит не равен нулю.
При исчерпании основного Codex-бакета (первичное или вторичное окно)
одно срабатывание с 60-секундным отсчётом. Отмена после срабатывания
не должна автоматически включать его снова. Маркер срабатывания
сохранять с идентификатором загрузки Windows, переживающим перезапуск
SideWidget. После перезагрузки ПК пользователь может включить функцию
снова. Проверка невозможна — выключение не выполнять.

Один общий разовый сценарий питания: таймер, завершение чатов или лимит.
Новый подтверждённый сценарий заменяет предыдущий. Отмена из таймера
отменяет также исходное наблюдение. Выход SideWidget отменяет активное
ожидание/отсчёт, но не очищает маркер уже использованного лимитного
срабатывания за текущую загрузку Windows. Никакого /f.

Сохранить графит/Medeo, темы и компактные формы. Проверять на 360/444 px.
В тестах подставлять действие питания, настоящее выключение не запускать.
