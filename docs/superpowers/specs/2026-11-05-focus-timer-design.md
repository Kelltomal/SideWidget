# Будильник, таймер и Pomodoro — дизайн

Дата: 2026-11-05. Статус: утверждено пользователем 2026-11-05. Pomodoro 25/5/15 после четырёх рабочих этапов; следующий этап вручную отдельной кнопкой после остановки сигнала.

## Цель
Добавить переставляемый и отключаемый модуль «Таймер» на главную и отдельную страницу внутри существующего окна SideWidget. Три режима: будильник, таймер, Pomodoro. Сохранить Medeo, графитовые поверхности и действующую геометрию шторки.

## Подходы
1. Только React: меньше изменений, но отсчёт в нативной свёрнутой строке и независимость от WebView ненадёжны.
2. Состояние в C# Core, управление через существующий bridge, нативное отображение в шапке и React-страница. Рекомендуемый вариант: одна достоверная модель для обеих поверхностей.
3. Отдельное системное окно и системные уведомления: дополнительный интерфейс и лишнее вмешательство в работу. Не требуется для поставленной задачи.

## Поведение
- Один активный отсчёт. Переключение вкладки режима само по себе его не отменяет; запуск нового явно заменяет текущий.
- Будильник: локальное время HH:mm, ближайшее наступление сегодня либо завтра; подпись даты снимает неоднозначность. Без ежедневного повтора в первой версии.
- Таймер: минуты и секунды, быстрые варианты 5/15/30 минут; запуск, пауза, продолжение, сброс. Пустое, отрицательное и нулевое значение отклоняются.
- Pomodoro: предлагаемые значения 25 минут работы, 5 минут отдыха, 15 минут длинного отдыха после четырёх рабочих этапов. Поля позволяют менять длительность. По умолчанию завершение ждёт клика, после которого следующий этап готов к запуску; автоматический переход оставлен на решение пользователя.
- В шапке вместо часов отображается оставшееся MM:ss либо H:mm:ss; при паузе — тот же остаток и текст состояния. Без активной сессии возвращаются часы.
- Завершение без звука, системных уведомлений, самопроизвольного раскрытия и перехвата фокуса. Текст «Время вышло» и мягкая пульсация светлой подложки обозначают состояние. Анимируется прозрачность; текст остаётся неподвижным и читаемым. Период спокойного дыхания 3 секунды; появление/погашение 200 мс. При отключённых системных анимациях — статичная подложка.
- Клик по сигналу в шапке или странице гасит его. В шапке этот клик не начинает перетаскивание. Обычное перетаскивание сохраняется.
- Состояние сохраняется локально после действий, не каждую секунду. Активный срок хранится абсолютной датой; сон компьютера и повторный запуск не обнуляют отсчёт. Просроченная сессия восстанавливается завершённой. Выключенный компьютер не пробуждается; закрытое приложение сигнал не показывает до запуска.

## Архитектура и координация
Новые Core/FocusTimer.cs, App/FocusTimerHeader.cs, Web/TimerPanel.tsx и timer.css. Точечные интеграции в Controller.cs, Protocol.cs, MainWindow.cs, PanelInteraction.cs и main.tsx. Команды timer.get/start/pause/resume/reset/dismiss, событие timer.changed. В браузерном preview — локальное сохранение и честное вычисление остатка по сроку.

Состояние хранится через существующий Store. Нативный DispatcherTimer проверяет срок независимо от видимости WebView. Секундные обновления React вычисляет по сроку; событие передаёт только изменение состояния.

Соседним чатам направлены сообщения с перечнем файлов. Общий release и мышь не используются до освобождения GUI переводческим чатом. Общие style.css/motion.ts остаются нетронутыми.

Web: три режима, запуск/пауза/сброс, ошибки, навигация и сохранение текущей сессии. Сборка web/native. Просмотр страницы 360/444/799 px, клавиатура, reduced motion. Нативная проверка свёрнутого отсчёта, завершения и клика после передачи GUI. Focused Impeccable detector; статус автоматических hooks сообщать только по фактическому выводу.
