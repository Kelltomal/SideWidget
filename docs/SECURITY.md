# Безопасность и приватность SideWidget 0.2

## Пульт в домашней сети

Новый опциональный Kestrel listener привязан к выбранному частному физическому LAN-адаптеру/IPv4 и его подсети. Он публикует отдельную React-поверхность, не общий WebView2 bridge. Через HTTPS разрешены только музыкальные команды и общая громкость выхода; микрофон и остальные модули закрыты. Строгие Host/Origin, JSON-поля, размеры/частота/параллельность, одноразовое приглашение, подтверждение кода на ПК, хеши ключей и отзыв доступа проверяются отдельно. Проверка доверия повторяется после чтения тела и перед выполнением ожидающей команды. Готовые команды не повторяются автоматически.

HTTP-порт отдаёт только setup, публичный CA и assets. Закрытый CA PFX защищён DPAPI CurrentUser; доверие Android устанавливает сам пользователь после сверки SHA-256 на ПК. HTTPS leaf обновляется до истечения без смены CA. Service worker кэширует оболочку, не API/авторизацию/треки; ключ телефона хранится в localStorage его HTTPS-origin. Отключение закрывает listener, отзыв аннулирует ключ. LAN-фильтр VPN/firewall не обходится. Этот путь расширяет прежнюю исключительно локальную границу по явному запросу пользователя. Подробности и непроверенные физические сценарии — [PHONE_REMOTE](PHONE_REMOTE.md).

Документ относится к текущему Product Reset. Прежний API Builder, Python Worker, серверные и CRM-модули удалены из активной поставки; их документация — только в `archive/0.1`.

## Граница доверия

Приложение работает от текущего пользователя (`asInvoker`), без администратора. Код WinUI/C# и локальный веб-bundle считаются доверенной установленной частью приложения. Пользователь или процесс, способный заменить эти файлы либо читать память текущего пользователя, находится за пределами этой границы. Подпись дистрибутива и проверенный установщик пока не заявлены.

WebView2 разрешает навигацию только внутри `https://sidewidget.local`; новые окна, downloads, разрешения сайтов, сохранение паролей и автозаполнение запрещены. Host objects не предоставляются. CSP блокирует внешние скрипты и `connect-src`; все внешние запросы выполняются отдельными C#-сервисами. Картинки ограничены локальными/data/blob источниками.

Мост проверяет origin, версию, UUID, структуру, повторные JSON-ключи, глубину и размер, разрешённые действия и имена параметров. Обработчики проверяют значения. Старые `api.*`, `files.run` и произвольные shell/JS/Python-команды не принимаются. Нативное подтверждение нельзя заменить полем `confirmed` из JavaScript.

## Что покидает компьютер

| Действие | Передаваемые данные |
| --- | --- |
| Погода | Введённое название города — Open-Meteo geocoding; найденные координаты — forecast endpoint. Геолокация по IP не запрашивается. |
| Курсы | GET официального XML ЦБ, без пользовательского текста и ключей. |
| Перевод | Исходный текст и выбранные языки — DeepL после явного действия. Ключ API добавляет C#. |
| Проверка интернета | DNS и ICMP либо HTTPS HEAD выбранного домена/IP. Нет фонового сканирования. |
| Открытие ссылки | Валидированный HTTP(S) URL — системному браузеру по клику; далее действуют настройки браузера. |

Калькулятор, единицы, цвета, QR, поиск Everything, список программ и локальный дневник не отправляются в аналитику. QR содержит исходный текст, не ссылку на скрытую публикацию. Пипетка не сохраняет и не отправляет снимок экрана. Everything использует локальный IPC.

`OnlineServices` использует фиксированные HTTPS-endpoint, timeout 15 секунд и чтение не более 1 MiB; redirects и cookies отключены. Проверка интернета принимает только домен/IP без пути, порта и credentials, допускает явно выбранные локальные IP, ограничивает параллельность и частоту. Это диагностическая функция, не универсальный HTTP-клиент. HTTPS измеряет запрос до заголовков, ICMP — echo round-trip; отказ ICMP не объявляет весь интернет отключённым.

## Секреты и локальные данные

Ключ DeepL вводится в нативный PasswordBox и сохраняется через DPAPI CurrentUser. SQLite содержит ссылку на файл секрета; React получает configured/provider/тип тарифа, но не ключ. Настройка не выполняет проверочный сетевой запрос. Авторизационный заголовок строится в C#, ключ не помещается в JSON-тело.

DPAPI не защищает от вредоносного процесса с доступом к тому же пользователю. SQLite, пути избранных приложений, история калькулятора, кэши погоды/курсов и Markdown-черновик не зашифрованы целиком. Recovery-копия черновика и отдельные UI-настройки/кэши находятся в localStorage профиля WebView2. Диагностический `--diagnostics` сохраняет геометрию окна; его файл не является ограниченным по размеру журналом аудита и не нужен для обычного запуска.

Старые настройки, секреты и результаты предыдущего продукта не удаляются. Backup БД проверяется до миграции и публикуется через временный файл. Повреждённые копии сохраняются; будущая версия схемы отвергается. Повреждённая БД с журналом транзакций требует отдельного восстановления. Пользовательские файлы не чистятся автоматически.

## Файлы, ссылки и системные действия

- Добавление приложения: Windows picker или drag/drop существующего локального `.exe`/`.lnk`. Для картинки отдельно выбирается цель запуска. Packaged app ID приходит из выбора настоящего окна. Launch выполняет только сохранённый элемент списка.
- `.lnk` проверяется на доступность цели, затем запускается штатным Windows Shell. Это выбранная пользователем программа/ярлык, не песочница. Аргументы ярлыка не считаются недоверенным кодом для автоматического выполнения: пользователь явно закрепляет и запускает файл.
- Открытие результата поиска допускается для путей, ранее выданных текущим процессом Controller и сохранённых в ограниченном allowlist; это **не только последний запрос**. UNC-пути отвергаются. Новый поиск на UI скрывает устаревший ответ, но не отзывает каждый предыдущий путь немедленно.
- `WebLink` допускает только абсолютные HTTP/HTTPS URL без credentials/control characters. `file:`, `javascript:`, shell-протоколы и другие схемы не передаются системному запуску через эту команду.
- QR сохраняется через FileSavePicker, без произвольного пути от UI. SVG допускает ограниченные геометрические элементы/атрибуты, запрещает DTD и внешние ресурсы. Изображение в clipboard — PNG/JPEG data URL.
- Markdown-предпросмотр создаёт React-элементы из текста, не вставляет raw HTML и не загружает внешние изображения. Это ограниченный локальный формат, не полный движок Markdown SellyBoard.
- Системные команды имеют фиксированный allowlist. Выключение, перезагрузка, сон и блокировка требуют нативного подтверждения. Принудительное закрытие приложений не запрашивается. Перезапуск Проводника явно возвращает «не реализован».
- Выбор пикселя/окна включает временные глобальные hooks. Отмена и завершение освобождают hooks/overlay; в фоновом состоянии постоянного перехвата клавиатуры этим механизмом нет.

## Ошибки, отмена и интеграции

Перевод можно отменить; прежний или поздний ответ не возвращается как успешный актуальный результат. Отмена запроса не отзывает уже переданный поставщику текст. После таймаута моста нужно проверить исход действия перед повтором. Создание задачи SellyBoard сохраняет client_key и исходную identity для явного безопасного повтора; неизвестный исход изменения статуса требует обновить карточку, автоматически запись не повторяется.

Клиент календаря SellyBoard использует отдельный календарный API-ключ с привязкой к пользователю и компании. Ключ вводится в нативной форме, хранится через DPAPI, не поступает в React. Cookie браузера не импортируются; права ограничивает сервер. Личный live ключ данного SideWidget ещё не подключён. Контракт и пробелы — [SELLYBOARD_CONTRACT](SELLYBOARD_CONTRACT.md).

Реальный DeepL-ключ не предоставлялся. Сетевые тесты перевода используют синтетические credentials и fake HttpMessageHandler. Windows-чтение сервисов не подтверждает выполнение всех команд управления; разрушительные действия не запускались. Непроверенные сценарии перечислены в [FEATURE_MATRIX](FEATURE_MATRIX.md) и [NEXT_STEPS](NEXT_STEPS.md).

## Бесплатный перевод
MyMemory использует фиксированный HTTPS endpoint /get; /set для публикации переводов не вызывается. Текст входит в query выбранного поставщика и отправляется только по кнопке. Google/Яндекс загружаются в отдельном скрытом WebView2. Каталог TranslationWebView2 и профиль Translation отделены от локального UI и браузеров пользователя; профиль постоянный, чтобы сохранять сессию ручной проверки. Это не InPrivate: сайт может сохранять cookies/cache, а WebView2 — данные навигации в этом профиле.

Разрешены фиксированные HTTPS origins translate.google.com и translate.yandex.ru/.com; дополнительно только путь /sorry или /sorry/… на www.google.com для проверки Google. CAPTCHA показывается внутри шторки с кнопкой «Отмена» и проходится только пользователем; автоматического обхода нет. Авторизационные/прочие неподдерживаемые переходы блокируются. Host objects, web messages, диалоги JS, popup, downloads и permissions отключены; mapping sidewidget.local отсутствует даже при видимой CAPTCHA. Исходный текст URL-кодируется, параметры reader сериализуются JSON. Результат читается только с origin переводчика после совпадения исходного поля и языка, возвращается как текст, не HTML. Обычный таймаут 35 секунд, ручная проверка до 10 минут; bridge для этих двух провайдеров ограничен 12 минутами. Отмена/новый запрос/завершение закрывают WebView. Ключ DeepL другим поставщикам не передаётся. Автоматического fallback нет. Native CAPTCHA smoke пока не завершён. [Отчёт](TRANSLATION_UPDATE.md).
