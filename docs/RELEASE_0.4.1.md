# SideWidget 0.4.1

Включает все функции [0.4.0](RELEASE_0.4.0.md): постоянный музыкальный пульт в домашней Wi-Fi-сети, монитор чатов и лимитов Codex с однократным выключением, календарь событий и монитор сайтов.

Для GitHub и его поддоменов монитор автоматически выбирает официальный GitHub Status, для OpenAI и ChatGPT — OpenAI Status. Структурированная сводка показывает наличие инцидента отдельно от доступности сайта с вашего ПК. Кнопка источника открывает обычную страницу статуса. Для остальных адресов остаётся DownRadar или ваша ссылка.

Число жалоб не выдумывается: официальная сводка инцидентов не является счётчиком жалоб. Неподдерживаемый ответ, CAPTCHA или ошибка сети сохраняют статус «неизвестно».

Проверки: 276 веб-тестов, TypeScript и production build; полный основной .NET-набор с новыми проверками выбора источника, JSON, кэша и неподдерживаемых ответов; Release-сборка Windows. Оба официальных API доступны с проверенного ПК.
