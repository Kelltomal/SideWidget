# Несколько экранов — проверка 5 ноября 2026

## Реализовано
Настройки → «Показывать на нескольких экранах»: выбор мониторов галочками, не менее одного выбранного экрана. Отдельная шторка на каждом выбранном подключённом мониторе, независимые раскрытие/закрепление, общие данные, тема, размер и положение. Горячая клавиша выбирает шторку под указателем; трей и регистрация сочетания единственные.

Выбор хранится по Windows monitor device interface ID, прежний индекс совместим. Недоступные выбранные экраны сохраняются, при их возвращении окна восстанавливаются; когда все выбранные недоступны, используется основной экран. Перенос в режиме нескольких выбранных экранов ограничен своим экраном. При отмене переноса восстанавливаются одновременно настройки и фактический экран окна.

DesktopState владеет единственными PersonalState/Launcher/Timer/Spectrum/Audio/Media/Online/Selly/PhoneRemote. Вторичное окно не уничтожает общие сервисы. Coordinator откладывает изменение набора окон до завершения ответа settings.save. Изменения состояния рассылаются остальным окнам; несохранённые настройки/текст дневника сохраняются. Ключи аварийного восстановления дневника отдельные для окон, старый ключ переносится однократно.

## Проверено автоматически
- Core/Infrastructure: `1025` проверок PASS, включая выбор/валидацию/старые настройки/перезапуск хранилища/протокол.
- Реальный исходник DesktopWindows с детерминированными адаптерами окна и dispatcher: `18` проверок PASS. Выбор/снятие, отложенное закрытие, отрицательные координаты, hotkey targeting, fallback, reconnect, отсутствие дублей, один audio broadcast и одно завершение общих сервисов. Это проверка координатора без создания WinUI окон.
- Полный web suite: `188` тестов / `21` файл PASS. Шесть новых тестов выбора экранов и сохранения несохранённых данных; прежний geometry flow обновлён под список экранов.
- TypeScript/Vite production build PASS. Native Debug build PASS, `0` предупреждений / `0` ошибок. Собирать web и native последовательно: Vite очищает dist, поэтому параллельный native copy может получить MSB3030 для старого hashed bundle.
- Read-only Windows probe: два реальных монитора, основной `2560×1440` в `(0,0)`, второй `1920×1080` в `(-1920,243)`. Непустые уникальные monitor interface IDs стабильны при двух последовательных чтениях; рабочие области корректны.
- Независимый code review: найдены и исправлены два дефекта переноса — потеря отключённых выбранных экранов и невосстановленный DisplayId при отмене. Focused review аудио-владельца не нашёл дефекта lifetime общих audio/spectrum/media.

## Визуальная проверка
Предпросмотр в отдельном headless Edge с явно тестовыми дескрипторами двух экранов, ширины 360/444 px. Снимки просмотрены: подписи и пояснение читаются, чекбоксы в текущем стиле, горизонтального переполнения нет. Снимки: `output/playwright/multi-display-settings-360.png`, `multi-display-settings-444.png`. Они не доказывают работу нескольких нативных окон.

Реальный Impeccable hook запускался, deterministic findings отсутствуют. Ручной `detect --json` для DisplaySettings.tsx/main.tsx/PersonalPanels.tsx вернул `[]`. Stale DESIGN sidecar отмечен отдельно, без несогласованной перегенерации. Dev preview CSP блокирует Vite HMR websocket — production policy не ослаблялась.

## Реальная проверка двух шторок после разрешения продолжить

Пользователь после физического Escape прямо разрешил продолжить проверку, затем отдельно подтвердил появление на втором экране. Проверен уже работающий `artifacts/combined-candidate-20261105-0535/SideWidget.App.exe`, PID `59616`, без новой сборки или перезапуска.

- Галочками выбраны оба реальных монитора и сохранены настройки. В процессе появились ровно два окна: основной `1316062` и вторичный `2887120` на левом экране; диагностика подтверждает отрицательный X и Y=243.
- Основная шторка осталась в настройках, вторичная независимо раскрыла главную с реальными медиаданными и отдельно свернулась. Контент первой не переключился вместе со второй.
- Переключение темы основной шторки на светлую обновило нативную шапку и веб-интерфейс второй шторки. Исходная тема «Как в Windows» восстановлена.
- Снятие второго экрана и сохранение оставило ровно одно основное окно. Повторный выбор создал ровно одно новое вторичное окно `59184262`; оно снова открылось на втором экране. Основная шторка продолжала показывать музыку, общий звук 12%, движущуюся временную позицию и визуализацию. Управление воспроизведением и громкостью при проверке не менялось.
- Финальное состояние: оба экрана включены, исходные остальные настройки сохранены. Нативный GUI-слот освобождён.

## Дополнительные ограничения
Физический hot unplug/reconnect, mixed DPI, перенос Escape, fullscreen/compact23 на каждом экране и сохранение после фактического restart отдельно не проверены. Продолжение отображения реальной музыки/спектра после снятия окна подтверждено; количество реальных volume callback и работоспособность сетевого пульта этим не измерялись. Прежний combined-кандидат имеет отдельную ошибку «Поделиться»: отсутствует distribution-files.json; исправление публикации ведёт владелец переноса/ZIP. Двухэкранная приёмка не означает приёмку переносимости, Android или физических принтеров.
