# Product Reset 0.2 — фактическая проверка

Дата: 5 ноября 2026, Europe/Moscow. Настоящее WinUI 3 / WebView2 приложение на Windows 11 x64, 96 DPI. Рабочий этап нового продукта, не завершение всего SPEC.

Свежий общий кандидат: [CANDIDATE_REPORT](CANDIDATE_REPORT.md). 932 C# checks / 142 web tests / TypeScript-Vite / native publish PASS; Windows harness 6 PASS, 0 FAIL, 1 SKIP. После разрешения продолжить GUI Google/Яндекс перевод и clipboard проверены; ручная CAPTCHA/возврат и запуск последнего кандидата ещё ожидаются. Ниже сохранена история предыдущих проверок; прежние числа тестов и performance JSON не являются результатом нового кандидата.

## Что удалено

- Из активных исходников и сборки: Python Worker/runtime, ApiEngine/API Builder, ProcessJob, старые widgets и серверные/GitLab/VPN/CRM/маркетплейсные экраны, подготовка CSV/изображений.
- Из обычного build/test/bootstrap исключён Python. Сохранены C#/WinUI/WebView2, SQLite, DPAPI, модель движения и встроенный Medeo.
- Старые исходники, релиз и Python-кэши перенесены в `artifacts/reset-backup`; прежние требования и снимки — в `docs/archive/0.1`. Они больше не определяют реализацию.

## Автоматические проверки

- Исторический прогон `scripts/test.ps1` до последующих изменений: **617 C# checks PASS**, включая 500 быстрых смен направления движения, 13 backup/recovery, 14 хранения избранного, 46 HTTP checks. **101 web test PASS**; TypeScript/Vite build проходил. Свежие результаты — в ссылке выше.
- Parser: дроби, отрицательные числа, скобки, проценты, запятая/точка, Unicode `× ÷ −`, границы сложности/finite. Процент — `x/100`; степень не заявляется.
- QR: независимый jsQR decoder после растеризации SVG/PNG/JPEG; кириллица, emoji, многострочный и длинный текст; quiet zone 4 модуля.
- Данные: будущая БД не понижается; повреждённые файлы сохраняются; backup публикуется после проверки. Два значка по 100 КБ и 40 по 150 КБ сохраняются. Реальное SQLITE_FULL проверяет rollback БД и памяти.
- HTTP: тело DeepL, DPAPI, отмена/поздний ответ, 429/offline, лимит ответа. Неверный JSON погоды использует кэш.
- Bridge: origin, UUID/envelope, лишние/повторные поля, запрет старых команд. Markdown-ссылки допускают только HTTP/HTTPS без credentials; file/javascript/ms-settings не исполняются.
- Постоянный Windows harness: `scripts/test-windows.ps1 -PublicOnline -NoRestore`: **7 PASS, 0 FAIL, 0 SKIP**. Реальные Core Audio/GSMTC/Everything/SystemMetrics, bounds обложек и Windows connectivity; отдельные HTTPS/ICMP. Временный `.lnk` fixture проверяет каноническую цель и rollback Undo; fixture EXE не запускается.

## Сохранность данных

Read-only сравнение настоящей БД с `backups/before-product-reset-v2.db`: **4 прежних ключа, все значения совпали**; текущая схема 2. Старые профили/данные не очищались. Секреты остаются в DPAPI; БД и дневник целиком не зашифрованы.

Тестовые вычисление/цвет/пара единиц и закреплённый Блокнот оставлены видимыми. Документы Блокнота не редактировались. Тестовые PNG/SVG/JPEG собраны в `artifacts/reset-qr-windows.*` проекта.

## Интерфейс и производительность

- Реальные ширины 360/444 px, раскрытый/свёрнутый режим, настройки, калькулятор, QR, цвета, единицы, поиск, приложения. Снимки: `docs/screenshots/reset-*`.
- Impeccable: исходниковый detector и отдельный отрисованный web-проход 360×568 без находок. Это не проверка native API. Fresh review семи снимков не нашёл материальных визуальных дефектов; отдельный verdict закрыл процессное замечание по brief. Полная приёмка SPEC не заявляется.
- DESIGN.md и `.impeccable/design.json` обновлены по готовому интерфейсу. Направление закреплено пользователем; seed и отсутствующий референс не выдумывались.
- Замеры включают дочерние WebView2: `performance-reset-expanded.json`, `performance-reset-collapsed.json`. Выборки 5/10 секунд, не гарантия для другого ПК. Главная: 3,12% одного CPU-ядра и 285,2 MiB private; установившийся свёрнутый режим: 0,31% ядра и 291,1 MiB private. Короткая выборка после UI-действий дала 25,62% ядра; она сохранена отдельно в `performance-reset-collapsed-transient.json`, причина пика не профилировалась. Working set может учитывать общие страницы; private bytes приведены отдельно.
- Startup diagnostic измеряет показ нативного окна/сохранение foreground, **не** полную готовность WebView2 и не серию холодных стартов. Последний показ окна: около 611 мс, foreground сохранён (`startup-reset.json`). FPS/120 Hz/нагрузка не приняты.

## Требует ключа или контракта

- DeepL: пользовательский API key Free/Pro. Реального перевода у провайдера не было; synthetic tests его не заменяют.
- SellyBoard: API календаря/базы знаний существует. Исследован локальный код, см. `SELLYBOARD_CONTRACT.md`. Нужны desktop-авторизация, ограниченные права, безопасный стенд и контракт учёта времени. Production/CRM не изменялись; задачи, время и синхронизация дневника не подключены.

## Ещё не реализовано или не принято

- SellyBoard connector, полноценные задачи/таймеры/дневник с конфликтами/синхронизацией, Windows reminders.
- Безопасный restart Explorer; прямой выбор audio output device; Wi-Fi/Bluetooth/DND через подтверждённые API. Есть честные кнопки страниц настроек, не фиктивные переключатели.
- GPU/температура/мощность/активность дисков; редактирование списка интернет-пресетов (свой адрес редактируется); named instance Everything.
- EXE-заглушка и Store AUMID не сопоставляются догадкой. Простые EXE/`.lnk` — по канонической цели; hosted/недоступные окна требуют ручного выбора.
- Drop/замена значка/Undo после подтверждённого window pick, отрицательные мониторы/разный DPI, HDR, hot unplug, сон/пробуждение, screen reader, touch и полная клавиатурная матрица требуют отдельной приёмки.
- Сон/shutdown/restart/lock **не выполнялись**. Терминалы и системные настройки через автоматизацию не запускались. Локальный unsigned portable x64; installer/updater не добавлены.
