# Пульт SideWidget на телефоне

Музыка играет на ПК; Android управляет ею через домашнюю сеть. ПК может быть подключён к роутеру кабелем. Яндекс Музыка должна быть открыта и видна в музыкальном блоке SideWidget. Доступность перемотки и переключений определяет проигрыватель Windows.

## Первое подключение и установка

1. На ПК откройте **SideWidget → Музыка → Пульт на телефоне**. Выберите домашний Ethernet/Wi-Fi и нажмите **Настроить сеть и подключить телефон**. Единственный домашний адаптер выбирается автоматически; функция изначально выключена.
2. Подтвердите стандартный запрос UAC Windows. Отдельный обработчик самого SideWidget сделает выбранную домашнюю сеть частной и создаст правило брандмауэра только для своего EXE, двух портов, текущего LAN-адреса и домашней подсети. Общий брандмауэр/VPN/другие сети не меняются. Приложение проверит результат, включит пульт и создаст QR. При отмене или ошибке QR готовности не показывается; кнопку можно повторить. Если адаптеров нет, подключитесь к домашнему роутеру.
3. Оставьте **Запускать SideWidget при входе в Windows** включённым для автозапуска после входа. Музыка сама не запускается.
4. Отсканируйте QR **Первый раз** камерой телефона. Откроется локальная инструкция для HTTPS.
5. Скачайте сертификат. Сравните SHA-256 с отпечатком в **Установка приложения на Android** на ПК. Установите файл как **сертификат центра сертификации** в Android: Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат. Пункты зависят от телефона; Android может потребовать PIN экрана.
6. Откройте HTTPS-пульт по кнопке на странице. Не отключайте проверку сертификата. Если QR истёк за время установки, нажмите **Новый QR подключения** на ПК, выберите **Сертификат установлен** и отсканируйте его.
7. Укажите имя телефона. Сравните шестизначный код на телефоне и в SideWidget, нажмите **Разрешить** на ПК. Браузер запомнит доступ.
8. В меню Chrome выберите **Установить приложение**. При доступности системного приглашения такая кнопка появится внутри пульта; иначе используйте меню браузера. Установка происходит только по действию пользователя.

CA создаёт ваш SideWidget; закрытый ключ хранится на ПК через Windows DPAPI. Установка CA добавляет доверенный центр сертификации на Android. Устанавливайте только свой сертификат после сверки с ПК. Для удаления доверия найдите **SideWidget Home Remote** в пользовательских доверенных сертификатах Android; отключение пульта само не удаляет CA с телефона. Системное доверие на Windows автоматически не меняется.

## Повторное использование

Откройте установленный пульт. Повторные QR и подтверждения не нужны. Открытый пульт восстанавливает связь после перезапуска SideWidget, сна ПК и потери Wi-Fi. Android может приостановить скрытое приложение; после открытия состояние обновится. Браузер на телефоне автоматически не запускается. При отсутствии связи кнопки отключаются; переключение трека после ошибки автоматически не повторяется.

Для постоянного адреса **закрепите IP ПК в DHCP-настройках роутера**. По умолчанию HTTPS — `47831`, первоначальная настройка HTTP — `47830`. При смене IP/портов старое установленное приложение не переносится автоматически: откройте новый QR, при необходимости переустановите приложение. После очистки браузерных данных нужно повторное подключение.

**Громкость ПК** — общая громкость текущего устройства вывода. Звук на телефон не передаётся. При исчезновении проигрывателя новый источник выбирается явно; старая команда не направляется другому плееру.

## VPN и доступ

SideWidget сохраняет конкретный домашний адаптер и локальный IPv4, не следует интернет-маршруту/DNS VPN. Туннельные и типичные виртуальные VPN-адаптеры исключены. Доступность домашней сети проверяется каждые пять секунд.

Если kill switch VPN блокирует LAN, включите **разрешение локальной сети / Allow LAN**. Приложение не обходит фильтры VPN/Windows Firewall. Телефон и ПК должны видеть друг друга в одной локальной подсети; гостевой Wi-Fi с изоляцией клиентов может мешать. Обнаружение ПК после смены DHCP-адреса не обещается.

Правило брандмауэра привязано к точному пути `SideWidget.App.exe`. После переноса/распаковки portable в другую папку нажмите native-кнопку настройки в этой копии: она перепривяжет своё узкое правило к новому пути. Глобальное разрешение для любого EXE не создаётся.

На ПК видны запросы и допущенные телефоны. **Отозвать доступ** запрещает последующие команды, включая ещё ожидающие выполнения; браузер удалит ключ при следующем запросе. **Выключить пульт** закрывает listener. До восьми телефонов, одноразовый QR действует пять минут.

Через сеть доступны только музыка и общая громкость выхода. Файлы, микрофон, буфер, запуск программ, системные действия, перевод и SellyBoard закрыты. HTTP отдаёт инструкцию/assets/публичный сертификат; API работает только по HTTPS. Service worker хранит оболочку, но не ключи, ответы API, треки и команды. Ключ хранится отдельно в localStorage защищённого origin. Обложки повторно не передаются, пока их версия известна клиенту.
