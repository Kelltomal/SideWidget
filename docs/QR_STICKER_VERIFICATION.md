# QR-стикеры — 2026-11-05

В генераторе QR после ввода текста появился раздел «Печать на стикерах»: шесть форматов SellyBoard и свой размер, внутренний отступ, 1–200 отдельных этикеток, необязательная подпись и предпросмотр. По умолчанию 60 × 60 мм, отступ 2 мм. Минимальный модуль QR 0,25 мм; при слишком плотном тексте печать блокируется с объяснением.

Требования уточнены в чате CRM «Исправить печать штрихкодов» (`01a1a2a1-1453-7103-be1d-6e65408d0a03`). Печатается QR исходного текста; правила Code 128 из CRM не переносятся.

Windows: `qr.print` открывает отдельное окно WebView2 с автоматическим диалогом печати, кнопками повторной печати и закрытия. Нет JavaScript, сообщений, host objects, внешней навигации, загрузок и разрешений. Перед HTML вставлен ограничительный CSP; сетевые ресурсы отклоняются. Ответ сообщает открытие окна, не факт физической печати. Закрытие во время подготовки отменяет ожидание. Ошибка открытия диалога показывается в окне и допускает повтор.
