# Архитектура SideWidget 0.2

Документ описывает текущий Product Reset. Полный целевой состав функций задан в [SPEC](SPEC.md); наличие сервиса в коде не означает завершённую Windows-приёмку. История прежнего API/Python-продукта находится в `archive/0.1`.

## Слои

| Проект | Ответственность |
| --- | --- |
| `SideWidget.Core` | `PanelMotion`, `Preferences`, hotkey parser, envelope/allowlist команд, проверка внешних веб-ссылок |
| `SideWidget.Infrastructure` | SQLite `Store`, личное состояние, DPAPI `SecretVault`, `OnlineServices` для Open-Meteo, ЦБ и DeepL |
| `SideWidget.App` | WinUI 3/HWND/WebView2, мост и нативные диалоги, Everything, Media, Audio, SystemMetrics, Internet, Launcher, ScreenPicker, системные действия |
| `SideWidget.Web` | React-панели, безопасный математический парсер, единицы/цвета/QR, локальный Markdown-предпросмотр, вызовы разрешённых команд |

Нет Python runtime/worker, универсального REST-конструктора, исполнения пользовательских скриптов или plugin SDK. Адаптер SellyBoard пока не реализован: [реальный серверный контракт](SELLYBOARD_CONTRACT.md) исследован, авторизация desktop-интеграции остаётся открытым вопросом.

## Окно и движение

Один экземпляр приложения защищён mutex. Основное top-level окно — единая шторка без системной рамки. Нативная шапка показывает день/время/дату из локального системного времени. Содержимое WebView2 размещено ниже и скрыто при свёрнутом состоянии. File picker, ContentDialog и временный overlay выбора пикселя/окна — отдельные интерактивные поверхности, не постоянные вторые панели.

`PanelMotion` моделирует Collapsed/Opening/Expanded/Closing и независимые Pinned/Editing/Suspended. Изменение цели начинается с текущей высоты. Основной путь изменяет высоту HWND, сохраняя верхнюю координату и ширину; регион ограничивает скруглённую поверхность. `--clip` оставлен диагностическим режимом. Нельзя выводить FPS или отсутствие всех click-through дефектов из одной геометрической проверки.

Положение хранится как индекс монитора и доля доступной ширины. Перенос шапки выбирает монитор под курсором; Escape возвращает прежнее положение. Числовые настройки разрешают 360–900 DIP по ширине и 360–1200 DIP по высоте; геометрия ограничена рабочей областью. Нижний правый захват меняет размер, сохраняет результат по завершении и отменяет Escape. Этот новый путь ещё не прошёл ручную Windows-проверку.

Наведение не активирует окно; явное взаимодействие переводит его в интерактивный режим. Ввод и нативные диалоги удерживают раскрытие. Есть системный reduced motion, обработка изменения DPI/дисплеев и приостановка при fullscreen-окне на выбранном экране. Отключение монитора, отрицательные координаты и смешанный DPI требуют отдельной приёмки.

## WebView2 и мост

Bundle обслуживается origin `https://sidewidget.local`; профиль WebView2 находится в `%LOCALAPPDATA%\SideWidget\WebView2`. Прежнего origin артефактов нет. CSP запрещает сетевые запросы JavaScript и внешние скрипты; сетевые возможности выполняются C#.

Envelope версии 1 содержит UUID `requestId`, `actionId` и объект `params`. `Protocol` проверяет origin, структуру, дубли ключей, глубину 16, предел 2 Mi символов JSON и allowlist имён параметров. Значения валидируются обработчиками. `Controller` ограничивает число незавершённых команд 32 и помнит 2048 последних requestId. Формы ответов и событий — [RESET_BRIDGE](RESET_BRIDGE.md).

Web bridge ждёт ответ до 180 секунд; таймаут не означает, что нативное действие точно не произошло. Повторять записи автоматически нельзя. Поиск и перевод отбрасывают устаревшие результаты на UI; нативный перевод отменяет предыдущий запрос и проверяет актуальность перед возвратом результата.

## Локальные инструменты

`tools.ts` выполняет расчёты без `eval`, с ограничением длины, числа токенов и рекурсии. Запятая/точка — десятичные разделители. Процент всегда делит операнд на 100. Расчёты binary64; финальный вывод округляется до 15 значащих цифр. Единицы вычисляются локально, включая температурное смещение и отличие MB/MiB/битов. HEX/RGB/HSL не поддерживает альфа-канал.

QR кодируется локальной закреплённой `qrcode` 1.5.4. SVG содержит векторные пути; PNG/JPEG создаются Canvas: чёрные модули, белый фон, целочисленный шаг и минимум четыре свободных модуля. Слишком длинный текст и недостаточный размер отвергаются без обрезания. Нативная часть валидирует формат и открывает Windows FileSavePicker; путь не поступает от JavaScript.

Дневник пока является одним локальным черновиком с ограниченным Markdown-предпросмотром. Ввод сохраняется в recovery-копию localStorage и затем в SQLite. Это не синхронизация по датам и не полная совместимость с Markdown SellyBoard. HTTP(S)-ссылки открываются через `WebLink` в системном браузере; raw HTML и внешние изображения не исполняются.

## Нативные и сетевые сервисы

- `EverythingService`: обычный экземпляр Everything, x64 SDK IPC, максимум 50 результатов. Глобальное состояние SDK сериализовано. При таймауте блокирующий SDK-вызов может ещё завершаться в фоне. Собственного индексатора нет.
- `MediaService`: Windows GSMTC; совместимые сессии и команды по заявленным возможностям источника. Растровая обложка ограничена размером/разрешением/временем; кэш привязан к сессии и треку.
- `AudioService`: Core Audio, общий выход, сессии приложений и default communications input для mute микрофона. Прямое переключение устройства не реализовано. Endpoint notification callback существует, но Controller пока не отправляет его в UI; состояние обновляется опросом.
- `SystemMetrics`: CPU по разнице счётчиков, RAM, свободное/общее место фиксированных дисков, uptime, батарея и скорость выбранного сетевого адаптера. Первый дифференциальный sample — `null`. GPU и активность дисков не измеряются.
- `InternetService`: локальное состояние Windows без внешнего запроса; ручные ICMP echo и HTTPS HEAD на домен/IP. Один запрос, минимум 5 секунд между началами, общий предел 6 секунд. HTTPS не следует redirect; длительность не называется ICMP-пингом.
- `LauncherService`: локальные `.exe`/`.lnk`, packaged-идентификаторы из window picker, иконки, rename/reorder/remove. Одношаговая отмена относится к изменению закрепления через выбор окна, не ко всем операциям списка.
- `ScreenPicker`: временный STA-поток, overlay и hooks на время выбора; отмена и освобождение ресурсов. Пиксель читается без сохранения снимка. HDR-точность не гарантируется.
- `OnlineServices`: Open-Meteo/DeepL и ЦБ; timeout 15 секунд, максимум 1 MiB ответа, redirects/cookies отключены. Кэш погоды по городу, fallback помечен stale. Курсы кэшируются на 30 минут, учитывают номинал. Ключ DeepL берётся из DPAPI.

React опрашивает музыку раз в 3 секунды, звук раз в 4, показатели раз в 5; опрос прекращается при скрытой панели/размонтировании. Интернет не пингуется автоматически. Это схема нагрузки, а не измерение CPU/RAM или плавности.

## Хранение и миграция

SQLite: `user_version=2`, таблицы `settings` и `journal`. Новые данные — ключи `personal.*`; устаревшие ключи не удаляются. Перенос старых настроек берёт ограниченные размеры, но не прежнюю раскладку серверных карточек.

Существующая БД проверяется read-only; схема выше 2 отвергается. До инициализации выполняется SQLite Backup API в `.partial`, проверка integrity/наличия settings, flush и публикация финального имени. Старый исправный backup не перезаписывается. Недописанный backup сохраняется как `.invalid-*`. Повреждённый основной файл без sidecars архивируется с уникальным именем, затем создаётся новая БД; при WAL/SHM/journal автоматического восстановления нет.

Квота 4096 SQLite pages применяется на каждом соединении; JSON одного значения ограничен 256 Ki символов. История калькулятора — 100 записей, цвета — 24, избранные пары — 20, приложения — 40. SQLite, WebView2 storage и черновики не зашифрованы целиком; секреты отдельно защищены DPAPI CurrentUser.
