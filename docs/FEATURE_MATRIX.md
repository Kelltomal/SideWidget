# Матрица возможностей SideWidget 0.2

Состояние Product Reset на 5 ноября 2026 года. «Реализовано» означает наличие рабочего пути в коде; «Windows-проверка» фиксирует только проведённое действие. Read-only проверка сервиса не подтверждает кнопки изменения состояния. Полный scope остаётся в [SPEC](SPEC.md), результаты финальной приёмки — в [TEST_REPORT](TEST_REPORT.md).

Узкий календарный API SellyBoard опубликован по отдельному отчёту владельца; клиент требует персональный ключ с привязкой account+company. Production-проверка временным ключом не подтверждает подключение данного SideWidget: личный ключ не настроен. [Контракт](SELLYBOARD_CONTRACT.md). Продажи, склады, серверы и другие CRM-разделы в продукт не возвращены.

Проценты калькулятора: `x% = x/100`; `200 + 10% = 200.1`. Итог — 15 значащих цифр. Конвертер единиц показывает до 12 значащих цифр; валютный UI — до 4 знаков после запятой. Эти правила не являются финансовой рекомендацией.

Архивы `docs/archive/0.1` и `artifacts/reset-backup` не считаются текущими возможностями. Прежний список «40 функций» отменён. Неотмеченные UI-сценарии остаются непроверенными, даже если соответствующий unit-тест зелёный.
