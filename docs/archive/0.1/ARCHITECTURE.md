# Архитектура

`SideWidget.App` создаёт единственное рабочее top-level HWND WinUI 3. Системный file picker — временное модальное исключение; он не меняет механику панели. Нативные TextBlock показывают день, время и дату из одного `DateTime.Now`. Статический React bundle размещается на виртуальном origin `https://sidewidget.local`; отдельный origin `https://artifacts.sidewidget.local` отдаёт только управляемую папку результатов.

`Protocol.Parse` проверяет origin, размер 64 КиБ, версию, UUID, структуру и повторные JSON-ключи. `ValidateParams` задаёт разрешённые actionId и список параметров. `Controller` выполняет команды, ограничивает очередь 32 запросами, отклоняет повторный requestId, проверяет сохранённые API-действия и управляет настройками. Native UI подтверждает изменения; поле `confirmed` из JS не принимается.

`ApiEngine` использует HttpClient без перенаправлений, cookies и прокси. DNS проверяется непосредственно при соединении; private/LAN запрещены без разрешения профиля. HTTP допускается только для явно разрешённого loopback. Два параллельных запроса, 10 секунд, ответ максимум 1 МиБ. Нет автоматических повторов записи. JSON-селектор — последовательность имён/индексов через точку, без исполнения выражений.

Python запускается по абсолютному пути включённого runtime через `ProcessStartInfo.ArgumentList`, без shell и окна консоли. Одно задание на процесс. UTF-8 NDJSON: progress/result/error, requestId, версия. stdout и stderr читаются параллельно; ограничены размер сообщения и число событий. Отмена передаётся stdin, через 600 мс процесс принудительно завершается вместе с деревом. Windows Job Object имеет `KILL_ON_JOB_CLOSE`. Два задания максимум; таймаут 2 минуты. После отмены поздний результат не принимается.

Данные SQLite: `settings(key,value)`, `journal(id,time,action,status,duration)`, schema user_version=1. Известное повреждение файла приводит к сохранению `.corrupt-TIMESTAMP` и новой базе; повреждённый JSON настройки — к значению по умолчанию. Старые API-метрики возвращаются как stale. Токены зашифрованы DPAPI CurrentUser в отдельной папке. Полные HTTP-ответы живут только в памяти интерфейса; кэшируется небольшое выбранное значение после маскирования секретов.

Шрифт: локальный Medeo Sans RC3 TTF для нативных элементов и WOFF2 для React, Medeo Mono для JSON/кода. Лицензия OFL сохранена. Выбран непрозрачный графитовый fallback; Mica и blur не включены.

Состояния панели: Collapsed/Opening/Expanded/Closing, независимые Pinned/Editing/Suspended. Смена цели берёт текущую высоту, очереди анимаций нет. Высота HWND меняется каждый тик; верхняя координата и ширина стабильны. SetWindowRgn ограничивает нижние скругления. При keyboard/reduced motion переход мгновенный. Во время ввода, picker и подтверждения скрытие заблокировано. При полноэкранном foreground на выбранном дисплее панель приостанавливается.
