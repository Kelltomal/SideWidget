# План реализации

1. Исследовать окружение, закрепить зависимости. Системные SDK не устанавливать; .NET распаковать в .tools. Исходная папка пуста, Git отсутствует.
2. Проверить нативный прототип: один HWND, шапка, две пустые карточки. Сравнить геометрическое изменение окна и clipping с SetWindowRgn, проверить обратимость, размеры и фокус. Не считать браузер доказательством HWND.
3. Вертикальный срез: Core/Infrastructure, строгий мост, SQLite и DPAPI, разрешённый GET/POST к локальному fake-сервису, NDJSON Python с файлами и отменой.
4. Полезный интерфейс: карточки, API-форма, обработка изображений 1500×2000, CSV, настройки, журнал. Сервисы без контрактов обозначить как ненастроенные.
5. Проверить release вне IDE, C# core/интеграции, Python, TypeScript, отрисованный интерфейс. Записать измерения и пробелы; заполнить матрицу всех 40 функций.

Приоритет проверки: невидимая область HWND; отмена и поздние ответы; недоверенный origin; повторная запись; неограниченные ответы и пути. Изменения production исключены. ТЗ разрешает самостоятельные обратимые решения и выполнение после короткого плана; дополнительное согласование архитектуры не требуется.
