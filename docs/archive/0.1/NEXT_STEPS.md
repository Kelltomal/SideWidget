1. Проверить на физических DPI 125/150/200%, нескольких мониторах с отрицательными координатами, отключением дисплея и sleep/resume. В текущей сессии системные настройки пользователя не менялись. Провести отдельную проверку fullscreen-игры и восстановления фокуса.

3. Расширить runtime-валидацию схем манифестов: сейчас исполняемый набор ограничен type=api и известным actionId; конфигурационная схема и permissions — описательные поля. Сторонний JS не поддерживается.
4. API Builder: полноценные JSON Schema формы, таблица/график JSON-результата, пагинация и OAuth/специфичная авторизация площадок. Сейчас доступны JSON-редактор, scalar/object result, Bearer, четыре разрешённых заголовка и multipart; UI редактирует Accept-Language.
5. Добавить явное управление сроком хранения артефактов с предпросмотром удаления; сейчас они не удаляются автоматически. Экспорт API-профилей/действий требует отдельного безопасного формата; текущий экспорт переносит только панель и раскладку.
