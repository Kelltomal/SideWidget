# SideWidget

Персональная рабочая утилита Windows 11 для API и доверенных Python-действий. Пользователь — разработчик SellyBoard и оператор маркетплейсов. Главная задача — выполнить конкретное действие и проверить фактический результат, не открывая отдельный рабочий центр.

Архитектура задана пользователем: C#, WinUI 3, WebView2, React/TypeScript, Python 3.13. Механика задана: единая панель 444 DIP, шапка 52 DIP, рост вниз до 620 DIP. Палитра задана ТЗ; по уточнению пользователя шрифт Medeo встроен в приложение. Новые концепции и декоративные метрики не нужны. Исходный скриншот в доступных вложениях отсутствует; визуальная опора — текстовые инварианты ТЗ.
