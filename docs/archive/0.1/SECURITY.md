# Границы безопасности

Приложение работает с `asInvoker`, без администратора. Сторонний исполняемый код не устанавливается. Только два зарегистрированных Python-действия: `images.export`, `csv.compare`. Отдельный процесс и Job Object управляют жизненным циклом, **не являются песочницей**. Доверенный Python имеет права текущего пользователя.

WebView2 загружает только локальный bundle; внешняя навигация, новые окна, загрузки, разрешения, сохранение паролей и host objects не предоставляются. CSP запрещает внешние скрипты и сетевые запросы JavaScript. Native bridge проверяет origin и параметры; строка widgetId не предоставляет полномочий. Манифесты не выполняют JavaScript. Локальный пользователь, способный менять файлы приложения, находится за пределами этой границы доверия.

DPAPI CurrentUser хранит токены отдельно от конфигурации. Значение вводится в нативный PasswordBox, JS получает лишь `hasSecret`. Worker запускается с очищенным окружением и не получает API-токены. API-ответы маскируют чувствительные имена полей и точное значение токена после JSON-декодирования, включая экранированные строки. Произвольные неизвестные персональные данные автоматически не классифицируются; автор разрешённого endpoint отвечает за состав ответа.

Разрешённые заголовки: Accept, Accept-Language, X-Request-ID, X-Correlation-ID. Authorization формирует только C#. Секретные поля в JSON-теле сохранённого действия запрещены. Bearer — единственный подключённый механизм авторизации. Настройка произвольных HTTPS-источников требует нативного действия пользователя; локальная сеть — отдельный флажок. TLS не отключается. Redirect запрещён, DNS IP проверяется перед соединением.

Запись требует нативного предпросмотра цели, тела и имён файлов. После сетевой ошибки/отмены отправленной записи результат считается неизвестным. Ретраев POST нет. Политика не заменяет сервисную идемпотентность; её контракт ещё не подключён. Разработка использует только loopback fixture. Production, сообщения, цены, остатки и перезапуски не выполнялись.

Журнал не содержит тела, адреса, токены, пути файлов или ответы. Экспорт содержит только геометрию и раскладку. API Body может содержать несекретные бизнес-данные и хранится в SQLite; база не зашифрована целиком. Артефакты остаются в профиле пользователя; автоматической очистки нет. DPAPI не защищает от любого вредоносного процесса того же пользователя.

Ограничения: отсутствует полноценная изоляция Python, подпись пакета и проверка установщика; окно между стартом процесса и присоединением к Job Object существует. При нормальном закрытии отменяются задания, Job Object завершает потомков. Права манифеста — описание доверенного зарегистрированного действия, а не защита произвольного кода.
