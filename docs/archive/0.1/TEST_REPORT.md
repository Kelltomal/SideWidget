# Проверка локального релиза 0.1.0

Дата: 4–5 ноября 2026, Europe/Moscow. Проверялось настоящее WinUI 3/WebView2 приложение вне IDE. Это локальный первый полезный релиз; полная аппаратная матрица и интеграции P1/P2 не приняты.

## Среда

- Windows 11, build 26200.9711, x64; AMD Ryzen 9 5900X, 24 логических процессора.
- Фактический DPI: 96 (100%). Размеры панели проверены 444×52/620 и 360×52/620 DIP.
- .NET SDK 10.0.403 локально; Windows App SDK 1.8.260921001, self-contained. WebView2 Runtime 156.0.4314.58.
- Python 3.13.14 embeddable и Pillow 12.0.0 включены в release. Отдельная системная установка Python для запуска не нужна.
- Medeo Sans TTF для WinUI, Sans/Mono WOFF2 для WebView2 и OFL включены в поставку. Сетевых загрузок шрифта нет.

TypeScript проверяет корреляцию/таймаут/поздний ответ моста и состояния компонентов. Эти числа — небольшой целевой suite, не исчерпывающее покрытие всех веток.

## Проверка настоящего окна

- Запуск `artifacts/release/SideWidget.App.exe --inspect --diagnostics`, без Node dev-сервера. Повторный запуск после сборки успешен.
- Начальная свёрнутая шапка отрисована до клика. Исправлена причина чёрного первого кадра: после SetWindowLong нужен однократный SWP_FRAMECHANGED. Проверено в прототипе и полном приложении, в нескольких последовательных запусках.
- Открытие кликом и Ctrl+Alt+Space, сворачивание горячей клавишей, закрепление. Шапка остаётся одна; ширина и верхняя граница не меняются при раскрытии. Модель обратимого движения проверена core-тестами; стабильный FPS не измерялся.
- Геометрия свёрнутого HWND — 52 DIP, WebView скрыт. Это подтверждает отсутствие большого скрытого прямоугольника HWND; отдельный клик-тест чужого приложения под нижней областью не проводился.
- Сохранение ширины 360 DIP через UI и её сохранность после перезапуска; возврат к 444 через UI также проверен. Поля удерживают панель раскрытой; длинные страницы прокручиваются под шапкой. Возврат на главную сбрасывает прокрутку.
- Реальный GET `/health` показал HTTP 200, длительность и время обновления. POST `/echo` прошёл через нативное подтверждение, вернул реально принятое тело с кириллицей.
- Windows FileOpenPicker выбрал тестовый PNG; встроенный Python создал отдельный PNG 1500×2000, WebView показал предпросмотр. CSV и отмена worker проверены автоматически; весь сценарий отмены большого задания вручную не прогонялся.
- Дата и день недели корректно сменились на 5 ноября в ходе проверки.
- Независимый code-review: пять обнаруженных дефектов исправлены; отдельная проверка последних оконных изменений важных регрессий не нашла.
- Impeccable: фактические post-edit hooks и один ручной detector (`design-detector.json`: `[]`). Это проверка Web-кода, не нативного HWND. Отдельный UI-review потребовал время обновления; повторный verdict: `ship` для этого исправления на 444/360. Обзор выполнен отдельным агентом по degraded-контракту: именованный agent selector отсутствует.

## Измерения

`scripts/measure.ps1`, по одному 5-секундному sample дерева SideWidget + 6 процессов WebView2, без активного Python-задания. Измерения сделаны перед последним добавлением подписи времени и исправлением квоты; не являются benchmark всех сценариев.

| Состояние | CPU, % одного ядра | Сумма working set | Сумма private bytes |
|---|---:|---:|---:|
| Раскрыта | 1,56 | 540,4 МиБ | 288,0 МиБ |
| Свёрнута | 3,75 | 534,4 МиБ | 285,8 МиБ |

Сумма working set повторно учитывает общие страницы; это не уникальная физическая память. CPU не нормализован на 24 логических процессора; короткие samples шумны, поэтому из разницы нельзя заключать, что свёрнутая панель постоянно дороже. Исходные записи: `performance-expanded.json`, `performance-collapsed.json`. CPU/память под длительной Python-нагрузкой, пиковые значения и рост после сотен циклов не измерены.

Диагностический старт двух последних запусков: около 422 и 609 мс от Process.StartTime до возврата ShowWithoutActivation, foregroundPreserved=true. Это время вызова показа, не время готовности WebView2 к первому действию. Кривая раскрытия рассчитана на 180 мс; фактические кадры и задержка hover не измерены.

## Непроверенное и ограничения

- DPI 125/150/200%, разные мониторы/отрицательные координаты, смена DPI, отключение дисплея, сон/пробуждение, fullscreen-игра и полная матрица восстановления фокуса.
- Реальное удаление WebView2/Python, потеря всей сети, screen reader, длительный soak и массовые параллельные задания. Обработка части этих состояний есть в коде; это не доказательство аппаратной проверки.
- SellyBoard, GitLab, маркетплейсы и Telegram не подключены. Проверки использовали только loopback и тестовые файлы; production не менялся, сообщения не отправлялись.
- Поставка x64 без подписи, установщика и автообновления. WebView2 Evergreen внешний. Python не является песочницей. Дополнительные ограничения API Builder/манифестов и все P1/P2 перечислены в FEATURE_MATRIX и NEXT_STEPS.
