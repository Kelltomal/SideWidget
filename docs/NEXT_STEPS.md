# Оставшаяся работа Product Reset

Текущий этап реализует локальные инструменты и Windows-адаптеры, но не закрывает весь [SPEC](SPEC.md). Статусы — в [FEATURE_MATRIX](FEATURE_MATRIX.md); доказательства последней сборки/приёмки — в [TEST_REPORT](TEST_REPORT.md). Старые серверные/Python/CRM-функции не возвращать.

## 1. Завершить проверку настоящего окна

- Resize: уменьшение высоты захватом и числовой размер уже проверены; осталось расширение захватом, Escape во время движения, потеря capture и край монитора.
- Перенос с сохранением y=0 и смена hotkey проверены. Осталось проверить отсутствие невидимой блокирующей области, полную матрицу фокуса hover/click, hotkey conflict, fullscreen и сон/пробуждение.
- DPI 100/125/150/200%, отрицательные координаты, смешанный DPI, отключение монитора, малый экран. Доступность с клавиатуры, screen reader, крупный режим, reduced motion, контраст и длинные строки.
- QR: все три формата сохранены через Windows и декодированы; отмена picker и наличие bitmap в clipboard проверены. Остались вставка в другое приложение и SVG clipboard.
- Пипетка/выбор окна: цвет и Escape, определение Блокнота и отмена подтверждения проверены. Остались правый клик, несколько мониторов, неверная цель, закрытие владельца и HDR.
- Программы: EXE/значок/запуск Блокнота проверены, native fixture проверяет .lnk identity и rollback. Остались packaged pin, картинка с отдельной целью, drop, замена значка, rename/reorder/remove и UI Undo после подтверждённого выбора.
- Остальные UI-flow: удаление истории калькулятора, все категории единиц/цветовые форматы, погода/валюта, локальный дневник и внешняя ссылка. Известные вычисление 320, пара 3,5 м/350 см, сохранение пары и копирование результатов уже проверены.

## 2. Довести Windows-сервисы и ограничения

- Проверить play/pause/seek/next/previous на нескольких источниках, смену трека, закрытие плеера, обложку и возврат из сна. Не обещать команды, отсутствующие в capabilities.
- Проверить громкость/mute/микрофон на согласованном устройстве, остановку сессии и device change. Подключить существующий endpoint callback к актуальному UI либо явно оставить polling; проверить отсутствие устаревшей сессии.
- Прямой выбор устройства, Wi-Fi/Bluetooth и DND исследовать только через поддерживаемые Windows API. До этого оставить понятные кнопки настроек.
- Спроектировать безопасный restart Explorer с проверкой конкретного shell-процесса и восстановлением. Текущий путь должен оставаться unavailable; не завершать все explorer.exe.
- GPU/температуры/мощность/активность дисков: выбрать проверяемый источник, права и частоту. Пока показывать недоступность. Не устанавливать драйверы ради метрик.
- Интернет: проверить реальные отрицательные состояния, IPv6, local IP и UI cooldown; дать редактирование списка пресетов, если сохраняется требование SPEC. Не включать фоновые пинги.

## 3. Подключить SellyBoard в пределах личных функций

Отправная точка — [SELLYBOARD_CONTRACT](SELLYBOARD_CONTRACT.md), основанный на локальных исходниках. API календаря и дневника уже есть. Требуются проверенный base URL/префикс, согласованный вход, узкие полномочия аккаунта/команды и отдельная проверка на безопасном стенде. Не читать credentials из `.env`, не копировать cookie браузера и не считать настройки интерфейса server-side scopes.

- Реализовать C# DTO/transport и contract tests на fake HTTP для существующих маршрутов. Calendar int64 ID передавать в WebView строками.
- Чтение периодов/карточек, timezone/all-day/end-exclusive/recurrence, флаг truncated. Создание личных задач с явным `visibility=private` и стабильным `client_key`.
- Сохранение полного task DTO с `version`, защита от стирания полей и отдельное решение `one/future/series`. 409 сохраняет черновик; неизвестный исход требует сверки, не повторного POST с новым ключом.
- Дневник по датам: `scope=personal`, чтение без создания, явное open/create, Markdown и `expected_version`, конфликт/повтор/отмена, локальные черновики. Ограниченный нынешний preview не объявлять полным Markdown SellyBoard.
- Серверный поиск только по личному дневнику требует расширения контракта либо ограниченной стратегии; текущий общий article search читает доступную базу знаний команды.
- Учёт времени и очередь: у изученного SB нет pause/resume/time-entry/atomic-next. Сначала определить отдельную модель сессии; пауза не меняет даты события и не завершает задачу. Если таймер пока локальный, назвать его локальным.

Никаких заказов, маркетплейсов, складов, серверных операций и других разделов CRM в этом адаптере.

## 4. Напоминания и внешние источники

- Реализовать Windows toast/scheduled reminders с идентичностью события, переносом/отменой, snooze, дедупликацией и согласованным поведением после сна/offline. Не подменять DND настройкой SideWidget.
- DeepL: пользователь предоставляет ключ в нативном диалоге; проверить реальный запрос, отмену, большие тексты, выбранные языки и QR результата. Пока есть только fake-HTTP доказательства, не end-to-end перевод.
- Погода/ЦБ: публичная read-only проверка уже выполнена; довести UI ошибок/stale/смены города, offline/restart, даты выходных и справочное округление. Сохранить источники и атрибуцию.
- При распространении проверить действующие условия и подходящий тариф Open-Meteo/DeepL; наличие работающего публичного endpoint не доказывает пригодность любого коммерческого использования.
