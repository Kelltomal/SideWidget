# Решения Product Reset 0.2

Актуально на 5 ноября 2026 года. Решения прежнего продукта сохранены в `archive/0.1/DECISIONS.md` и не задают scope новой шторки.

## Продукт и стек

SideWidget — повседневная Windows-панель. Серверы, DevOps, GitLab/VPN, маркетплейсы, универсальный API Builder, исполнение Python, обработка товарных изображений и CSV исключены. Старые исходники/поставка сохранены в `artifacts/reset-backup`; `.venv` и Python runtime перенесены в `unused-python`. Пользовательские данные не стираются.

Сохранены C# + WinUI 3 + WebView2/React, SQLite, DPAPI, локальный Medeo. Номер текущей ветки поставки — 0.2.0. Bootstrap готовит только локальный .NET SDK; build/test/package не требуют Python. Архив ZIP не равен подписанному установщику и не доказывает полной приёмки.

## Оболочка

Основной путь — изменение реальной высоты HWND, а не большое невидимое окно под капсулой. Шапка остаётся одна, верхняя координата и ширина не меняются от раскрытия. Существующая конечная модель движения сохранена; клавиатурные/reduced-motion переходы могут быть мгновенными. FPS без измерения не обещается.

Расположение хранится относительно выбранной рабочей области монитора. Разрешены размеры в заданных пределах, перенос шапки и Escape-отмена. Добавлен отдельный нижний правый захват resize; код готов, ручная проверка ещё требуется. Нельзя выдавать прежние проверки ширины через настройки за проверку нового drag-resize.

## Локальные инструменты и хранение

Калькулятор — собственный ограниченный парсер арифметики, без `eval`. Процент всегда `x/100`, а не банковская операция «прибавить долю базового числа». Binary64 и 15 значащих цифр зафиксированы в техническом контракте; история сохраняет выражение и результат. Единицы и цвета не требуют сети.

Для QR закреплена `qrcode@1.5.4`, источник проверен в [официальном репозитории](https://github.com/soldair/node-qrcode). Все форматы проверяются независимым декодером; SVG остаётся векторным. PNG/JPEG имеют белый фон и свободное поле. Размер или длина не исправляются скрытым обрезанием текста.

Новые настройки используют `personal.*`; старые ключи сохранены. Исправлены доказанные дефекты Store: копия до обработчика повреждения блокировала recovery, недописанный final backup считался успешным, будущий `user_version` понижался. Теперь используются read-only inspection, проверенный `.partial` и rename; повреждённые артефакты сохраняются, WAL-семейство не восстанавливается автоматически. Регрессии сначала воспроизвели ошибки, затем прошли.

Локальный дневник сохраняет recovery-копию и SQLite-черновик. Предпросмотр ограничен безопасным набором Markdown; HTTP(S)-ссылки открываются системным браузером через отдельный валидатор. Это ещё не дневник по датам и не совместимый клиент полного редактора SellyBoard.

## Windows и сеть

Everything использует существующий индекс через официальный SDK IPC. Не устанавливается собственный индексатор. Медиасессии и звук используют Windows API, а не чтение чужих интерфейсов. Недоступные данные возвращаются как unavailable/null, а не выдуманные нули.

Wi-Fi, Bluetooth, уведомления/«Не беспокоить», питание и выбор аудиоустройства открываются в настройках Windows, пока нет подтверждённого прямого управления. Перезапуск Проводника не заменён завершением всех explorer.exe. GPU и активность дисков отсутствуют; это видимые ограничения, не выполненные функции.

Интернет-проверка разделяет Windows connectivity, ICMP и HTTPS. Запрос только вручную, с фиксированными лимитами. Неответивший ICMP не означает отсутствие интернета.

Погода — Open-Meteo с указанием модельного характера и источника. Валюты — опубликованный XML ЦБ, `rate=value/nominal`, кросс-курс через базовую валюту, UI округляет результат до четырёх знаков. Ответы и кэши имеют отдельные времена данных/получения. При ошибке схемы погоды сохранённый прогноз остаётся доступен как stale.

Перевод — официальный DeepL API Free/Pro, ручная отправка, собственный ключ в DPAPI. Реальный ключ не предоставлялся; доказаны fake-HTTP контракт, отмена/поздний ответ, ошибки и ограничение размера. Публичные Open-Meteo и ЦБ проверены отдельно opt-in командой; эти проверки не расширяют доказательства DeepL.

## SellyBoard

Изучены локальные исходники CRM без изменения кода, БД, секретов и production. API календаря и личного дневника существует. Пробел — узкая desktop-авторизация; текущий вход использует широкую веб-сессию и CSRF. Учёт фактического времени, pause/resume и next-task в изученном контракте отсутствуют. Даты события нельзя подменять таймером.

Подключение остаётся отдельным этапом. Никакие CRM/заказы/склады не входят в этот адаптер. Поля, версии, client_key и ограничения записаны в [SELLYBOARD_CONTRACT](SELLYBOARD_CONTRACT.md).
