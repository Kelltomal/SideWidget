# SideWidget 0.4.5

- SideWidget подтверждает завершение последнего запроса по событию сервера Codex в локальном журнале и сверяет ID запроса с SQLite.
- Отсчёт привязан к завершившемуся запросу. Новый запрос отменяет его. Если новый запрос успел завершиться между проверками, отсчёт начинается заново с 60 секунд.
- Перед автовыключением по чатам SideWidget заново проверяет выбранные чаты и очередь. Если журнал недоступен или завершение нельзя подтвердить, выключение блокируется.

На реальном чате проверены запуск, отмена и повторный запуск отсчёта в тестовом процессе без команды выключения. Отдельный тест подтвердил блокировку при появлении запроса в очереди перед действием.
