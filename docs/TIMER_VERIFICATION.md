# Проверка автономного таймера

Состояние: реализация готова; native GUI slot ожидает передачи от единого координатора. Это не утверждение о выпуске общего приложения.

## Поведение
Будильник на ближайшее локальное HH:mm; таймер от 1 секунды до 24 часов с паузой; Pomodoro 25/5/15 после четырёх работ. Длительности Pomodoro редактируемые 1–180 минут. Следующий этап только отдельной кнопкой после остановки сигнала. Один активный отсчёт; новый запуск явно заменяет текущий. Состояние в SQLite personal.focusTimer.v1, browser preview отдельно в localStorage sidewidget.focusTimer.v1. Дедлайн продолжает идти во сне/при закрытии и восстанавливается при запуске приложения. Закрытое приложение не пробуждает компьютер и не показывает сигнал до следующего запуска.

Шапка вместо часов показывает остаток, паузу или готовый этап; завершение — неподвижный текст «Время вышло», плавная подложка opacity 0–0.16 / 3 секунды, reduced motion статично 0.12. Вход/выход 200 мс. Клик по шапке при сигнале останавливает его до начала drag и до EnterInteractive. Без звука, раскрытия по таймеру и изменения foreground. Геометрия, resize, системная рамка и чужие переводы/API сохранены.

Сбой записи при истечении не блокирует сигнал: срок уже был сохранён, ringing выводится сразу, сохранение повторяется. Пользовательские команды сохраняются до изменения live state. Будильник учитывает offset целевой даты; пропущенное при DST время смещается на величину скачка, как JavaScript Date.

## Обязательный следующий native GUI слот
Не запускать параллельно с визуальным/переводческим чатом. На согласованном свежем native output:
1. Открыть модуль Таймер, 10 секунд, запустить; свернуть и убедиться, что шапка показывает уменьшающийся остаток вместо часов.
2. Перейти в другое приложение; дождаться истечения. Зафиксировать текст/пульсацию без звука, раскрытия и перехвата фокуса.
3. Клик по сигналу: часы возвращаются, drag и открытие не начинаются; второй обычный клик раскрывает шторку.
4. Проверить нативный reduced motion и сохранение через перезапуск.
5. Pomodoro: по завершении клик гасит сигнал, отображает 05:00 готового этапа, countdown не идёт до отдельного запуска.
6. Не потерять последние изменения рамки/геометрии и встроенного перевода; выпуск только через координатора.
