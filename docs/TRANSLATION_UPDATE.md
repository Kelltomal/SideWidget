# Перевод Google / Яндекс — 5 ноября 2026

Статус: кандидат собран; native Google/Яндекс перевод и копирование проверены после нового разрешения пользователя продолжить GUI. Ручное решение CAPTCHA ещё не подтверждено. Последний кандидат ожидает запуска после закрытия стороннего процесса artifacts/release.

## Действующее требование

Google и Яндекс сохранены, ключи не нужны. SideWidget передаёт текст и языки скрытой странице, считывает результат в собственное поле. По последнему прямому запросу пользователя CAPTCHA показывается внутри приложения для ручного прохождения; после проверки перевод продолжается автоматически. MyMemory остаётся вариантом по умолчанию, DeepL — дополнительным API со своим ключом. Прежнее удаление Google/Яндекса и видимый постоянно сайт не являются итоговым решением.

## Реализация

- URL-prefill штатных сайтов; проверка точного исходного текста, целевого языка и стабильного результата. Google — до 5000 символов, Яндекс — до 10000. Сам ввод ничего не отправляет.
- Новый WebView на запрос, прозрачный и clipped до 0×0, без ввода; внутренний viewport 800×600. Основной интерфейс остаётся видимым, кроме ручной проверки.
- Отдельный постоянный профиль Translation в TranslationWebView2: cookies проверки сохраняются между запросами. Профили браузеров пользователя не используются. Это НЕ InPrivate; cookies/cache/данные навигации могут сохраняться.
- Фиксированные HTTPS origins переводчиков; Google дополнительно разрешает www.google.com только /sorry и /sorry/… . Внешние страницы авторизации не открываются.
- При ручной /showcaptcha, Google /sorry или видимых CAPTCHA-контролах тот же WebView показывается в теле шторки. Автоматическая /showcaptchafast с hidden inputs остаётся скрытой. Нативная строка содержит название сервиса, инструкцию и «Отмена». Сессия и запрос не заменяются. После первого корректного результата сайт скрывается; после стабильного результата поле получает перевод.
- Нет host objects, web messages, sidewidget.local mapping, popup, downloads, permissions, JS dialogs, сохранения паролей или autofill. Это сохраняется и при видимой CAPTCHA. Reader получает параметры через JSON serialization; возвращается обычный текст, не HTML.
- Обычный таймаут 35 секунд; с первой ручной проверкой — 10 минут, без бесконечного продления. Bridge для Google/Яндекса ограничен 12 минутами. Отмена/новый запрос/завершение закрывают WebView и восстанавливают UI; поздний ответ не становится текущим.
- Автоматического решения CAPTCHA и fallback нет. DeepL-ключи остаются DPAPI и не передаются другим сервисам.

## Фактические проверки

- Native Яндекс: Hello world вызвал /showcaptchafast. В чистом тестовом профиле выяснено: это автоматическая проверка с hidden inputs, самостоятельно возвращающаяся на /. Её ложное раскрытие исправлено. Диагностика только тестовой фразы удалена из кода; пользовательские профили не очищались.
- Native Google и Яндекс: Hello world = «Привет, мир» в наших полях, clipboard exact PASS. Яндекс: новый Good morning = «Доброе утро». Site UI при обычном переводе не показывался. Кнопка «Отмена» показанной проверки сработала; Escape внутри WebView потребовал отдельного accelerator, повторная живая ручная CAPTCHA для проверки не появилась.
- До нового CAPTCHA UX production reader на реальных страницах в headless Edge вернул «Привет, мир» для обоих сервисов. Артефакты output/playwright/google-dom-result.json и yandex-dom-result.json. Это НЕ native smoke.
- Новые regression checks: строгие origins/path/port/userinfo для ручной проверки, запрет чтения результата с Google challenge origin; bridge остаётся pending после 5 минут и ограничивает потерянный ответ. RED/GREEN подтверждён.
- Общий прогон scripts/test-release.ps1: 932 C# checks, 142 web tests; TypeScript/Vite PASS; Windows harness 6 PASS / 0 FAIL / 1 SKIP (public-online не запрошен). Логи artifacts/verification/20261105-035618.
- Native self-contained publish кандидата artifacts/candidate-20261105-035803 прошёл. Новый кандидат НЕ запускался.
- Read-only review не нашёл определённого блокирующего дефекта; live solve/return и Escape при фокусе внутри WebView остаются обязательными. Проверить также повторный перевод, Cancel во время инициализации и закрытие приложения.

Реальный DeepL-ключ не использовался. Проверка прежнего ВИДИМОГО Google/Яндекса не заменяет приёмку нового скрытого пути.

## Ограничения

Потребительские сайты не являются стабильным API-контрактом. Изменение DOM, consent или неподдерживаемый redirect может остановить перевод; показывается ошибка, MyMemory можно выбрать вручную. Ресурсы сайта загружаются в фоне. CAPTCHA проходит пользователь; подтверждённого результата нового ручного сценария пока нет. Пользовательские DB/ключи/профили не удалялись.
