# Разовый таймер питания

Быстрые действия → Питание → «Выключить через…» или «Перезагрузить через…».
Введите часы и минуты, затем подтвердите системное действие. Например:
0 часов 30 минут, 2 часа 0 минут либо 1 час 30 минут. Пустое поле равно нулю.
При 0 часов 0 минут появляется предупреждение; действие не назначается.
Максимальная задержка — 24 часа, минуты — 0–59.

Раздел «Таймер» показывает остаток времени, срок и кнопку отмены.
Если обычный таймер не активен, отсчёт также виден в нативной шапке.
Одновременно действует одно задание питания для всех окон. Новое задание
заменяет прежнее после подтверждения. Выполнение однократное, без
принудительного завершения приложений. Несохранённые документы могут
задержать завершение Windows.

SideWidget должен оставаться запущен. Сворачивание панели не отменяет
задание; выход из приложения отменяет. После сна просроченное задание
выполняется при следующем обновлении часов.
