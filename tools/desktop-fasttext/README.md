# Классификатор рабочего стола

SideWidget читает имя файла и до 6000 символов из TXT, Markdown, CSV, TSV, DOCX, XLSX, PPTX, ODT, ODS и ODP. У остальных форматов учитывается имя. PDF и сканы обрабатываются по имени. Расширения изображений, архивов, логов и медиа определяют их папку по умолчанию.

Модель обучена через fastText на синтетических русских и английских примерах. Темы — финансы, договоры и право, проекты, учёба, личное, здоровье, поездки и авто. Сжатые веса встроены в `SideWidget.Infrastructure.dll`. Для запуска хватает обычной сборки SideWidget, вычисления идут на CPU. Кандидаты с низкой оценкой или конфликтующими правилами остаются без галочки.

Промпт принимает команды на русском, например «Разложи счета по годам, а скриншоты оставь на столе» или «Перенеси архивы в папку Резерв». Две модели fastText распознают действие и тип файлов. Код извлекает и проверяет имя папки, а также поддерживает ранее доступные точные формулировки. Поддерживаются перенос в папку, группировка по годам и исключение из переноса. SideWidget выводит текстовый план и список файлов перед переносом. Год сначала ищется в имени, затем в извлечённом тексте. Если на выбранном шаге год отсутствует или найдено несколько разных лет, файл остаётся на столе. Скриншоты определяются по характерным именам, например `Screenshot` или `Снимок экрана`.

Команда «Игры помести в папку игры, а программы в папку программы. Батники и запуски серверов в отдельную папку» добавляет в предпросмотр ярлыки, программы и скрипты. Подсказки учитывают имя и цель ярлыка. Для переноса этих файлов нужно поставить галочки вручную.

Команда «Разложи документы по темам, а всё непонятное оставь на столе» использует тот же классификатор документов. Предпросмотр отмечает уверенные предложения и объясняет, почему пропущены документы с неясной темой. Команда просматривает файлы верхнего уровня рабочего стола.

Формат `Папка: слово, фраза` тоже доступен. Одно совпавшее назначение имеет приоритет над моделью. Слова сравниваются без учёта регистра, пробелы и знаки препинания служат разделителями.

## Воспроизведение

```powershell
python -m pip install fasttext-wheel==0.9.2 numpy==1.26.4
python tools/desktop-fasttext/train.py
python tools/desktop-fasttext/train_prompts.py
& ./.tools/dotnet/dotnet.exe run -c Release --project tests/SideWidget.Tests
```

Для обучения нужен Python 3.12. Скрипт пересоздаёт встроенный ресурс и сверяет экспорт с предсказаниями fastText. Тест запускает тот же C#-код, что и предпросмотр SideWidget, на 30 базовых, 24 разговорных русских и 24 тематических примерах. Тестовые файлы не входят в обучающую выборку. Проверка печатает точность отмеченных предложений, покрытие, число пропущенных неоднозначных файлов и время предпросмотра.
