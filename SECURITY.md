# Security policy

## Report a vulnerability privately

Open the SideWidget repository’s **Security** tab and select **Advisories**, then **Report a vulnerability** if available. Keep reproduction details and proof-of-concept code out of public issues and pull requests.

If private reporting is unavailable, you can open an issue asking the maintainer to enable it. Keep the issue limited to that request and wait for a private channel before sharing details.

Include the affected SideWidget version, Windows build, steps to reproduce, and the impact in your private report. Remove credentials and personal data from attachments. Use the public [issue tracker](https://github.com/Kelltomal/SideWidget/issues) for ordinary bugs.
